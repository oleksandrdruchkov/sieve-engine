# Sieve Engine

**Sieve** — це архітектурний рушій логічного виведення (Inference Engine) на базі спрямованого ациклічного графу міркувань (DAG) та Байєсівських мереж довіри.

Рушій реалізує багаторівневу фільтрацію:
* **Фільтрація шуму та «щоабизму»:** оцінка атак через матрицю очікуваних втрат ($EL = P \times I$)[cite: 12].
* **Семантичне сито:** злиття дублікатів та пенальті за кореляцію моделей для запобігання ехо-камерам[cite: 12].
* **Епістеміологічне сито:** ієрархія доказів від $T4$ (судження LLM) до $T0$ (математичні розрахунки та код)[cite: 12].
* **Goal Fidelity Sieve:** захист від ерозії бізнес-вимог (Goal Drift) під час мікрохірургії графу.
